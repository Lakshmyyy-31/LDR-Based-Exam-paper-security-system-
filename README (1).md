      **EXAM PAPER DISTRIBUTION SYSTEM**

**PROBLEM STATEMENT**

          Examination papers contain important and confidential information and requires a secure storage to prevent from unauthorized access. This project aims to develop a simple, low-cost security system that detects unauthorized access conditions and provides an immediate alert.

**COMPONENTS REQUIRED**

*     LDR Sensor Module  
*     LED  
*     Buzzer  
*     Breadboard  
*     Connecting Wires  
*     9V Battery  
*     Security Box

**WORKING PRINCIPLE**

           The LDR sensor is placed inside the examination paper security box. The system continuously monitors the light intensity.

* When the sensor detects darkness, the LED turns ON and the buzzer sounds.  
* When light falls on the sensor, the LED turns OFF and the buzzer remains OFF.  
* Thus, the system provides an alert whenever the predefined dark condition is detected inside the box.

**PROCEDURE**

       1\. Connect the LDR sensor, LED, and buzzer on the breadboard.

2\. Power the circuit using a 9V battery.

3\. Place the sensor inside the security box.

4\. Close the box and test the sensor condition.

5\. When darkness is detected, the LED glows and the buzzer sounds.

6\. When light falls on the sensor, the LED and buzzer turn OFF.

7\. Verify the system operation under different lighting conditions.

**OBJECTIVE**

       1\. To protect examination papers from unauthorized access.

         2\. To provide an instant alert using a buzzer.

         3\. To design a simple and low-cost security system.

         4\. To demonstrate the use of an LDR sensor in security applications.
